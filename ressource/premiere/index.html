    Exercice 1.1.3 : Masse molaire

    Ecrire un programme permettant de calculer la masse molaire de n'importe quelle entité chimique (atome, composé ionique, molécule).
    Remarque :
    - L'entité sera une chaine de caractère qui ne contient ni parenthèses, ni charges, ni complexes. Ex : C6H12O6, Fe2O3, CuSO4
    - On utilisera un dictionnaire contenant les masses molaires atomiques les plus utilisées.
    - On utilisera le module Regex pour chercher un motif (ici)

    import re #Module regex

M={"H":1.0,"C":12.0,"N":14.0,"O":16.0,"F":19.0,"Na":23.0,"S":32.0,"Cl":35.5} #en g/mol

entite="NaCl"

#Le motif à chercher est le suivant : 
    #Majuscule suivi de minuscule ou pas --->elem
    #Suivi d'un nombre ou pas ---> num
motif = re.compile(r'(?P<elem>[A-Z][a-z]?)(?P<num>\d*)')

masse_molaire=0

for m in motif.finditer(entite):
    element=m.group("elem")
    nombre=m.group("num")
    if nombre=='':
        nombre=1
    else:
        nombre=int(nombre)
    masse_molaire=masse_molaire+M[element]*nombre

print(masse_molaire)
