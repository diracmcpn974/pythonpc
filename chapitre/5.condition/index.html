    5. Structures conditionnelles

    L'ordre dans lequel les instructions sont écrites dans le programme est important puisqu'à priori ces instructions s'exécutent les unes à la suite des autres. Il s'avèrent que parfois, pour pouvoir modéliser certains problèmes, les instructions ne doivent s'éxécuter que sous certaines conditions. Si telle condition est vraie ou non, alors telles instructions seront exécutées ou pas. Pour cela, on utilise une structure conditionnelle.

    5.1 Comment créer une structure conditionnelle ?

    Pour créer une structure conditionnelle, il faut utiliser la syntaxe suivante : 

    1
2
3
4
    if condition : 
    instruction1
    instruction2
    ....

    Remarques :

    • le mot clé if peut se traduire par : "Si".
    • Attention à l'indentation des instructions à l'intérieur de la condition !

    Il est important de noter que dans la structure précédente, toutes les conditions if seront vérifiées une par une que la condition précédente est vraie ou fausse. Parfois, il est préférable algorithmiquement que dès qu'une condition est vraie, les autres conditions qui suivent ne soient pas vérifiés. Pour cela on utilise le mot clé elif ce qui peut se traduire par "Autrement Si". Dans ce cas, tant que la condition précédente est fausse, la condition suivante est vérifiée.

    5.3 Et si aucune condition n'est vraie ?

    Il suffit d'ajouter le mot clé else à la fin pourqu'on ait des instructions qui s'exécutent quand même si aucune des conditions précédentes n'est vraie.

    instruction1
    instruction2
    ....
elif condition2 : 
    instruction1
    instruction2
    ....
else : 
    instruction1
    instruction2
    ....

    Remarques :

    • le mot clé else peut se traduire par : "Autrement".
    • Il se place toujours à la fin !

    La température d'ébullition de l'acide citrique vaut 310°C et sa température de fusion vaut 153°C. Dans quel état physique se trouve t-il à 0°C, à 20°C, à 100°C ?

    def etat_physique(t,t_fus,t_ebul):
    """ t (float): température en °C de l'espèce chimique
        t_fus (float): température de fusion en °C de l'espèce chimique
        t_ebul (float): température d'ébullition en °C de l'espèce chimique
    \nRenvoie l'état physique de l'espèce chimique (str)
    """
    if t<=t_fus:
        etat="solide"
    elif (t>t_fus)and(t<=t_ebul):
        etat="liquide"
    elif t>t_ebul:
        etat="gazeux"

    return etat

etat1 = etat_physique(0,153,310)
etat2 = etat_physique(20,153,310)
etat3 = etat_physique(100,153,310)

print(etat1,etat2,etat3)

    Ce qu'il faut savoir faire avant de continuer :

    • Créer et utiliser des structures conditionnelles avec if, elif, else.
    • Comprendre la différence entre if, elif, else.
