    3. Types de données

    Lors de la modélisation de phénomènes physiques ou chimiques, nous allons être amené à utiliser différents types de données et les stocker dans des variables. Python en propose une multitude (voir doc) et permet même de construire nos propres types de données. Voici les plus utiles dans notre cadre :

    • les nombres entiers (int)
    • les nombres flottants (float)
    • les booléens (bool)
    • les chaînes de caractères (str)
    • les listes (list)

    3.1 Les nombres entiers et flottants

    Un nombre entier (int) est un entier relatif et un nombre flottant (float) est un nombre à virgule. Par exemple :

    3.3.5 La notation scientifique et les chiffres significatifs

    Avec le formatage de chaînes de caractères, on peut aller encore plus loin et afficher une valeur numérique en notation scientifique ou en respectant les chiffres significatifs.

    Pour afficher une valeur numérique en utilisant la notation scientifique, il suffit d'utiliser le formatage {:.pe} où p désigne le nombre de chiffres aprés la virgule.

    Test 3.3.5.1 : Notation scientifique 1
    1. Tester le code suivant : 
      1
2
      print("{:.2e}".format(0.0003256813)) #2 chiffres après la virgule et de plus la valeur est arrondie
print("{:.5e}".format(0.0003256813)) #5 chiffres après la virgule et de plus la valeur est arrondie
    Test 3.3.5.2 : Notation scientifique 2

    Le calcul d'une période T donne le résultat suivant : 0.00286971 s.
    1. Afficher une phrase donnant le résultat en notation scientifique arrondie au millième.

    1
2

print("La période vaut {:.3e} s.".format(periode))

    Pour afficher une valeur numérique avec le bon nombre de chiffre significatifs, il suffit d'utiliser le formatage {:.pg} où p désigne le nombre de chiffres significatifs.

    Test 3.3.5.3 : Chiffres significatifs 1

    Test 3.3.5.4 : Chiffres significatifs 2

    Les listes sont des conteneurs qui peuvent stocker un ensemble de données de différents types.
    Une liste est représentée par des crochets [ ] avec les éléments séparées par des virgules ,. Par exemple :

3

    2.6 Comment convertir un type de données en un autre type ?

    En utilisant ces 3 fonctions élémentaires int(), float(), str(), on peut convertir :

    • un nombre flottant ou un entier au format chaine de caractères en un nombre entier. Exemples : int(333.258) , int("10")
    • un nombre entier ou un nombre flottant en une chaine de caractères.
      Exemples : str(10) , str(333.258)
    • un nombre entier ou un nombre quelconque au format chaine de caractères en un nombre flottant.
      Exemples : float(10) , float("10"), float("333.258"),
    Test 2.6 : Conversion

    3. Convertir le texte "78.21" en nombre.
    1
