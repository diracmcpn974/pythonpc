    4. Fonctions

    En programmation, une fonction est un bloc de code réutilisable qui effectue une tâche spécifique. Elle permet d'organiser et de structurer un programme, d'éviter la répétition de code et de rendre celui-ci plus lisible.

    Dans les chapitres précédents, nous avons vu et utilisé certaines fonctions basiques comme print(), type(), str(), ... Mais il est aussi possible de créer ses propres fonctions.

    4.1 Comment créer ses propres fonctions ?

    Pour créer une fonction, il faut utiliser la syntaxe suivante :

    def nom_fonction (argument1, argument2,....) :
    """ documentation """

    instruction1
    instruction2
    ....

    return mon_resultat

    • On commence par le mot clé def suivi du nom de la fonction.
    • Entre parenthèses, on définit les paramètres d'entrée appelés arguments séparés par des , et suivies des :. Les arguments ne sont pas obligatoires et peuvent être définis avec une valeur par défaut.
    • Les triples guillemets """ sont les fameux docstrings qu'on a vu dans le chapitre 1 et qui permettent d'expliquer ce que fait la fonction, quels sont les arguments attendus, leurs types, ... Ils sont facultatifs mais fortement recommandés pour pouvoir faire comprendre aux autres comment utiliser correctement la fonction.
    • Dans le bloc indenté, on écrit ligne par ligne les instructions à réaliser.
    • Et enfin on retourne un résultat avec le mot clé return. Le retour d'un résultat n'est pas obligatoire.

    • Attention à l'indentation des instructions à l'intérieur de la fonction !
    • Une fonction qui ne retourne aucune valeur de sortie retournera par défaut la valeur None. Il est recommandé de créer une fonction qui renvoie toujours un résultat en sortie pour plus de modularité.

    4.2 Comment utiliser une fonction ?

    Pour cela, il suffit d'appeler la fonction en attribuant des valeurs aux arguments entre parenthèses. Il y a deux façons d'attribuer des valeurs en entrée :

    • soit on écrit les valeurs les unes à la suite des autres en respectant l'ordre des arguments définis par la fonction. Python comprendra alors que la 1ère valeur est pour l'argument1, la 2ème valeur pour l'argument2, ...
      Ex : resultat = nom_fonction(variable1, variable2,....)
    • soit on indique dans le désordre que telle valeur est pour l'argument1, telle valeur pour l'argument2 mais dans ce cas les arguments de la fonction doivent être suivis obligatoirement du symbole = et de la valeur correspondante.
      Ex : resultat = nom_fonction(argument2 = variable2, argument1 = variable1, ...)
    • soit en combinant les deux façons mais dans ce cas les arguments suivis de = et de la variable doivent être positionnés à la fin.
      Ex : resultat = nom_fonction(variable1, variable2, argument4 = variable4, argument3 = variable3, ...)

      def vecteur_variation_vitesse (vx1,vy1,vx2,vy2) :
    """ vx1,vy1 (float,float) coordonnées du vecteur vitesse v1
        vx2,vy2 (float,float) coordonnées du vecteur vitesse v2
    \n Renvoie les coordonnées du vecteur variation de vitesse (float,float) """
    delta_vx = vx2 - vx1
    delta_vy = vy2 - vy1
    return delta_vx,delta_vy 

###Test de la fonction###

print(vx,vy)

vx,vy = vecteur_variation_vitesse(8,2,10,3) #Même valeurs mais ordre non respecté
print(vx,vy)

print(vx,vy)

vx,vy = vecteur_variation_vitesse(2,3,vy2=10,vx2=8) #En combinant les deux  
print(vx,vy)

    Remarques :

    • Il convient de respecter le nombre d'arguments dans une fonction. Par exemple, une fonction qui possède 5 arguments doit être utilisée avec 5 valeurs. Une valeur supplémentaire peut générer une erreur. Par contre si on attribue moins de valeurs mais que les arguments possèdent des valeurs par défaut alors il n'y aura pas d'erreurs.
    • Il convient aussi de respecter le type des arguments. Par exemple, si l'argument attendu est une chaîne de caractère et qu'on attribue un nombre entier, une erreur sera systèmatiquement générée.
    • Pour éviter toutes ces erreurs, il est recommandé de toujours lire la documentation associée aux fonctions afin de les utiliser correctement.

    4.3 Ai-je accés aux variables définies à l'intérieur d'une fonction ?

    Il faut bien comprendre que lorsqu'on crée ou utilise une fonction, toutes les variables définies à l'intérieur de cette fonction seront considérées comme des variables locales. C'est à dire que ces variables ne seront pas accessibles dans le programme principal. Elles n'existeront que pendant l'exécution de la fonction et seront détruites aprés l'éxecution de la fonction.

    Remarque : il est toutefois possible de rendre accessible une variable à l'intérieur d'une fonction en créant une variable globale avec le mot clé global mais ceci est à éviter à tout prix !

    Afin d'éviter ce genre de problème, il n'est pas recommandé de modifier un objet existant dans le programme principal à l'intérieur d'une fonction. Il est préférable de retourner une valeur avec la fonction et de modifier l'objet avec cette valeur dans le programme principal.
