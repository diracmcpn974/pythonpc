    10. Module scientifique Scipy

    Le module Scipy est destiné aux calculs scientifiques avancés tels que les dérivations, les intégrations, les résolutions d'équations, les ajustements , les interpolations, les transformées de Fourier, ... .

    La documentation du module est disponible ici.

    10.1 Comment modéliser des points expérimentaux par une fonction ?

    Pour modéliser des points expérimentaux par une fonction mathématique quelconque, on va utiliser la fonction curve_fit(....) du sous-module optimize qui utilise la méthode des moindres carrés non linéaires.

    Les arguments utiles de la fonction sont :

    • f qui est la fonction de modélisation qu'il faudra définir au préalable
    • xdata qui est le tableau d'abscisses des points expérimentaux
    • ydata qui est le tableau d'ordonnées des points expérimentaux

    Cette fonction renvoie en sortie :

    • popt qui sont les valeurs optimisées des variables de la fonction de modélisation
    • pcov qui est une estimation de la covariance des variables de la fonction

    10.2 Comment réaliser une interpolation ?

    L'interpolation est une opération mathématique qui consiste à joindre des points donnés, par des portions de courbes. Par exemple, dans le cas d'une interpolation linéaire, les portions de courbes sont des segments de droite. Elle permet d'estimer les points intermédiaires de la courbe situés entre ceux donnés initialement.
    L'interpolation d'une fonction où l'on passe exactement par tous les points est différente de l'approximation par une fonction (ci-dessus 10.1) où l'on passe au plus proche des points.

    Pour faire cela, on va utiliser la fonction make_interp_spline du sous-module interpolate avec les arguments utiles suivants :

    • x qui représente le tableau des abscisses des points à interpoler.
    • y qui représente le tableau des ordonnées des points à interpoler.
    • k qui représente le degré du polynome utilisé pour l'interpolation. (Ex : linéaire k=1)

    Cette fonction renvoie alors un objet BSpline qu'on utilise comme une fonction.

    10.3 Comment résoudre une équation à une inconnue ?

    Une équation \(f(x) = a\) peut se ramener sous la forme \(F(x) = 0\) en posant \(F(x) = f(x) - a\). Cela revient donc à trouver les racines de la fonction \(F\). Pour cela, on peut utiliser la fonction root_scalar(....) du sous-module optimize avec les arguments suivants :

    • f qui représente la fonction mathématique
    • bracket qui représente l'intervalle dans laquelle se trouve la ou les solutions
    • x0 qui représente une valeur estimée de la solution

    Remarque : Selon le solveur, l'argument bracket ou x0 est requis (voir ici)

    La fonction renvoie alors un objet RootResults qui contient en autres l'attribut root soit la ou les solutions de l'équation.

    import numpy as np
import matplotlib.pyplot as plt
import scipy.optimize as sco

x = np.linspace(0, 180, 200)

def y(x):
    g = 9.81
    alpha=40*np.pi/180 #en radians
    v0=40
    y=-g/(2*v0**2*np.cos(alpha)**2)*x**2+x*np.tan(alpha)
    return y

fig, ax = plt.subplots()
ax.plot(x,y(x))
ax.grid(True)
ax.set_ylim(0,35)

sol = sco.root_scalar(y,x0=150)
print(sol.root)

sol = sco.root_scalar(y,bracket=[100,200])
print(sol.root)

plt.show()

    10.4 Comment résoudre un système d'équations à plusieurs inconnues ?

    Pour résoudre un système d'équations quelconques à plusieurs inconnues, on peut utiliser la fonction root(....) du sous-module optimize avec les arguments suivants :

    • fun qui représente la fonction mathématique
    • x0 qui représente un tableau de valeurs estimées des solutions

    La fonction renvoie alors un objet OptimizeResult qui contient en autres l'attribut x soit les solutions de l'équation.

    Dans le cas d'un système d'équations linéaires, il est possible de se ramener à une équation matricielle. Pour cela, il faut d'abord mettre le système sous la forme \(A\cdot X = b\)
    Par exemple, pour un système d'équations linéaires à deux inconnues : \(\begin {cases} a_{1x}\cdot x + a_{1y}\cdot y = b_1 \\ a_{2x}\cdot x + a_{2y}\cdot y = b_2 \end {cases}\)
    on a : \(A = \begin {pmatrix} a_{1x} & a_{1y} \\ a_{2x} & a_{2y} \end {pmatrix}\) , \(X = \begin{pmatrix} x \\ y \end{pmatrix}\) et \(b = \begin{pmatrix} b_1 \\ b_2 \end{pmatrix}\)

    Pour la résolution, on peut utiliser alors la fonction solve(....) du sous-module linalg

    Les arguments utiles de la fonction sont :

    • a qui représente la matrice carré A
    • b qui représente le vecteur colonne b

    Cette fonction renvoie en sortie :

    • x qui est le vecteur colonne X contenant les solutions

    10.7 Comment résoudre une équation différentielle d'ordre 1 ?

    Pour résoudre une équation différentielle ordinaire, on se ramène à un problème de Cauchy : \(\begin{cases} \frac{dy}{dt} = f(y,t) \\ y(t_{0})=y_0 \end{cases}\) où y(t) est une fonction à valeurs réelles, vectorielles ou complexes

    On utilise ainsi la fonction solve_ivp(...)du sous-module integrate avec les arguments utiles suivants :

    • fun qui représente la fonction \(f\) sous la forme \(f(t,y)\)
    • t_span qui représente l'intervalle d'intégration de \(t_{0}\) à \(t_{f}\). Ex :[t0,tf]
    • y0 qui représente la condition initiale \(y_0\). Ex : [y0]
    • method qui représente l'algorithme d'intégration voir ici (optionnel)
    • t_eval qui représente le tableau de valeurs de \(t\) entre \(t_{0}\) et \(t_{f}\) à partir duquel la solution sera calculée. (optionnel)
    • dense_output = True si l'on souhaite avoir une solution sous forme d'objet (Par défaut,dense_output = False)
    • args qui représente les arguments à passer à la fonction fun (optionnel)

    La fonction renvoie un objet OdeResult avec entre autres les attributs suivant :

    • t : un tableau de valeurs de \(t\) entre \(t_{0}\) et \(t_{f}\)
    • y : un tableau de valeurs de \(y\) à \(t\)
    • sol : un objet d'instance OdeSolution si dense_output = True utile pour l'interpolation.

    10.8 Comment résoudre une équation différentielle d'ordre 2 ?

    Pour résoudre une équation différentielle de 2d ordre avec la fonction solve_ivp(...), il faut se ramener à un système d'équations différentielles de 1er ordre tel que :

import matplotlib.pyplot as plt  

def systeme(t,r,g):
    y = r[0]
    vy = r[1]
    z = r[2]
    vz = r[3]

    dy_dt = vy
    dvy_dt = 0
    dz_dt = vz
    dvz_dt = -g

    10.9 Comment calculer la transformée de Fourier discrète d'un signal discret ?

    La transformation de Fourier discrète (TFD) permet d'obtenir une représentation spectrale discrète (spectre échantillonné) d'un signal discret (signal échantillonné) sur une fenêtre de temps finie (échantillonnage borné dans le temps).
    Pour rappel, la TFD d'un signal échantillonné \((a(0),a(1),...,a(n-1))\) s'écrit :
    \(A(k)= \sum_{m=0}^{n-1}a(m)e^{-j2\pi k\frac{m}{n}}\) avec \(0\leq k\leq n\) (Plus d'infos).

    Afin d'éviter une perte d'information et un repliement de spectre, il faut que le théorème de Shannon soit respecté, c'est à dire que la fréquence d'échantillonnage doit être supérieure au double de la fréquence maximale présente dans le signal : soit \(F_e > 2 f_{max}\) (Plus d'infos).

    Pour réaliser une TFD, on va utiliser la fonction ftt(...) du sous-module fft avec comme argument utile x qui représente le tableau de valeurs du signal échantillonné. La fonction renvoie alors un tableau de valeurs de la TFD.
    Les fréquences correspondantes à ces valeurs sont obtenues en utilisant la fonction fttfreq(...) du sous-module fft avec comme arguments utiles :

    • n qui représente le nombre d'échantillons
    • d qui représente la période d'échantillonnage \(T_e\)

    La fonction renvoie alors un tableau des fréquences contenues dans le signal échantillonné.
