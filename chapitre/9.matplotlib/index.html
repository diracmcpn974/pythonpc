    9. Module graphique Matplotlib

    Pour représenter visuellement des données sous forme graphique, on va utiliser le module Matplotlib. Ce module permet d'interagir avec le graphique. Pour plus de détails, la documentation du module est disponible ici.

    L'importation du module peut se faire de cette manière : import matplotlib.pyplot as plt.

    9.1 Comment tracer une courbe simplement ?

    Pour tracer une courbe simplement, il suffit de disposer de points de coordonnées x et y dans deux tableaux 1D de même longueur. Ces points peuvent être soit obtenus expérimentalement soit générés à partir d'une fonction mathématique.

    import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0,18,100) #Abscisses de la position du ballon
y = -0.08*(x-10.3)**2 + 14.28 #Ordonnées -->Trajectoire parabolique 

fig, ax = plt.subplots() #Crée un objet Figure et un objet Axes               
ax.plot(x, y)  # Trace les points (x,y) dans l'objet Axes.
plt.show() #Affiche la fenêtre

    Dans le programme précédent,

    • A la ligne 4 et 5, on génère les points de coordonnées (x,y) dans des tableaux séparés.
    • A la ligne 7, on crée avec la fonction plt.subplots() un objet Figure dans fig qui représente la figure principale de la fenêtre d'affichage et un objet Axes dans ax qui représente le ou les graphiques de la figure (et non les axes contrairement à ce qu'on pourrait penser...).
    • A la ligne 8, on trace la courbe à partir des tableaux x et y dans le graphique ax avec la méthode .plot(x,y)
    • A la ligne 9, on affiche la fenêtre avec la fonction plt.show()

    Le graphique apparaît alors dans l'onglet Graphes au format image.

    9.3 Quels types de courbes peut-on tracer ?

    Différents types de courbes peuvent être tracés (voir ici). On va se limiter au tracé :

    • de lignes avec des points déja vu avec la méthode .plot(...) d'un objet Axes.
    • d'un nuage de points avec la méthode .scatter(...) d'un objet Axes.
    • d'un histogramme avec la méthode .hist(...) d'un objet Axes.

    9.3.1 Tracé de lignes avec des points

    Par défaut, l'utilisation de la méthode .plot(x,y) d'un objet Axes trace une ligne entre deux points consécutifs. Il est possible de modifier l'apparence de la courbe en ajoutant des arguments à la méthode. En voici quelques unes :

    • marker pour ajouter un style de points à la courbe ("x" pour des croix, "." pour des points, "s" pour des carrés, ... )
    • markersize pour la taille des points (Ex : markersize = 15)
    • color pour la couleur de la courbe ("blue","red","orange",....)
    • linestyle pour le style de ligne de la courbe (- par défaut pour des lignes, -- pour des traits, : pour des pointillés,....)
    • linewidth pour l'épaisseur de la ligne (Ex : linewidth = 15)

    9.3.2 Tracé d'un nuage de points

    Généralement, on utilise ce tracé lorsqu'on a des mesures expérimentales. La méthode est .scatter(....) et s'utilise comme la méthode .plot(....). Voici quelques arguments utiles pour modifier l'apparence des points :

    • marker pour ajouter un style de points à la courbe ("o" pour des ronds, "*" pour des étoiles, "D" pour des losanges, ... )
    • s pour la taille des points (Ex : s = 200).
    • facecolor pour la couleur intérieur des points ("green","cyan","yellow",....).
    • edgecolor pour la couleur du contour (si existant) des points ("black","grey","brown",....)
    • alpha pour la transparence des point entre 0 et 1 (Ex : alpha = 0.5)

    Remarque : Les arguments s, facecolor, edgecolor, alpha acceptent des listes de même longueur que le nombre de points pour personnaliser chaque point individuellement.

    9.3.3 Tracé d'un histogramme

    Pour rappel mathématique, un histogramme est un graphique permettant de représenter les séries continues dont les valeurs du caractère étudié ont été regroupées en « classes ». Le tracé de l'histogramme nous sera utile lors de l'exploitation de la variabilité de mesures indépendantes d’une grandeur physique. La méthode est .hist(....) et s'utilise avec les arguments suivants :

    • x qui représente le tableau de valeurs de la grandeur physique.
    • bins qui représente le nombre de classes. Par défaut, bins = 10.
    • range qui représente la valeur minimale et la valeur maximale des classes. Ex : range = (0,20)
    • density qui trace les fréquences de chaque classe. Ex : density = True
    • facecolor pour la couleur intérieur des rectangles.
    • edgecolor pour la couleur du contour des rectangles.

    Cette méthode renvoie trois objets :

    • le premier est un tableau donnant l'effectif de chaque classe
    • le deuxième est un tableau donnant les intervalles de chaque classe
    • le troisième est un conteneur d'objets utilisés lors du tracé

    9.4 Comment personnaliser un graphique ?

    Il existe une multitude de façons de personnaliser un graphique avec Matplotlib. Pour plus de détails, ici

    Voici quelques options utiles :

    • Ajouter un titre avec la méthode .set_title("text") d'un objet Axes.
    • Légender les axes x et y avec les méthodes .set_xlabel("text") et .set_ylabel("text") d'un objet Axes.
    • Afficher une grille sur le graphique avec la méthode .grid(True) d'un objet Axes.
    • Afficher la légende des courbes en ajoutant l'argument label="text" dans les méthodes .plot(...), .scatter(...), .hist(...), ... , puis utiliser la méthode .legend() d'un objet Axes.
    • Travailler dans un repère orthonormé avec la méthode .axis('equal') d'un objet Axes.
    • Fixer les bornes inférieures et supérieures des axes x et y avec les méthodes .set_xlim(inf,sup) et .set_ylim(inf,sup) d'un objet Axes.
    • Passer l'axe des abcisses en échelle logarithmique avec la méthode .set_xscale('log') d'un objet Axes.
    • Modifier les graduations sur les axes voir ici et ici

    9.6 Comment afficher plusieurs graphiques dans une même fenêtre ?

    Pour afficher plusieurs graphiques dans une fenêtre, il suffit de considérer la fenêtre comme une grille avec des lignes et des colonnes. Pour cela, la manière la plus simple est d'ajouter dans la fonction plt.subplots(...) les arguments nrows=... et ncols=... qui représentent le nombre de lignes et de colonnes de la grille. Dans ce cas, la fonction renverra une liste d'objets Axes et non plus un seul objet Axes comme pour un seul graphique

    Il est aussi possible de partager les mêmes axes x ou y entre les graphiques avec les arguments sharex=True ou sharey=True

    Pour éviter le risque que les graphiques se chevauchent on peut rajouter l'argument layout="constrained"

    9.7 Comment tracer un vecteur ?

    Pour tracer un vecteur, on utiliser la méthode .quiver(....) d'un objet Axes avec les arguments suivants :

    • x qui représente l'abscisse de l'origine du vecteur ou une liste d'abscisses
    • y qui représente l'ordonnée de l'origine du vecteur ou une liste d'ordonnées
    • u qui représente l'abscisse du vecteur ou une liste d'abscisses
    • v qui représente l'ordonnée du vecteur ou une liste d'ordonnées
    • color qui représente la couleur de la fléche
    • angles='xy' qui indique que la direction des flèches est définie par les composantes du vecteur telles que le vecteur pointe de (x,y) vers (x+u et y+v)
    • scale qui représente un facteur de réduction de la longueur des flêches sur le dessin (plus scale est grand, plus les flèches sont courtes.)
    • scale_units qui représente l'unité de référence pour la norme des vecteurs. Si elle est dans la même unité que celle des axes x et y alors on choisit scale_units='xy'. Autrement on peut prendre la valeur par défaut scale_units='width' (la largeur du graphique)
    • units='dots' qui indique que la taille des flêches sur l'écran est mesurée en pixels. Utile pour éviter de modifier la taille des flèches lors d'un zoom.

    9.8 Comment réaliser une animation graphique ?

    L’animation graphique avec le module matplotlib permet de créer des graphes dynamiques, où les données changent au cours du temps, ce qui est très utile pour visualiser des phénomènes évolutifs (mouvements, oscillations, simulations, etc..).
    Le module matplotlib.animation fournit une classe appelée FuncAnimation(....) qui va appeler une fonction de manière répétitive afin de mettre à jour les éléments du graphique. Les arguments utiles sont :

    • fig qui représente la figure de la fenêtre d'affichage
    • func qui représente la fonction à définir qui sera appelé à chaque image de l'animation
    • frames qui représente le nombre total d'images de l'animation (Par défaut,None)
    • init_func qui représente la fonction à définir pour initialiser le graphique. Il sera appelé uniquement à la première image (Par défaut,None)
    • interval qui représente la durée entre 2 images en millisecondes (Par défaut,200)
    • repeat qui indique si l'animation est répétée ou non. (Par défaut,True)
    • blit qui permet d'optimiser l'affichage (Par défaut,False)

      import numpy as np
import matplotlib.pyplot as plt
import matplotlib.animation as ani

f=2       # fréquence de l'onde en Hertz
c=2       # célérité de l'onde en m/s
A=0.5     # amplitude de l'onde en m

periode_spatiale = c/f #longueur d'onde en m
T = 1/f # T en s

x = np.linspace(0, 5*periode_spatiale, 200)
dt=0.01 # pas temporel (en s)
temps = np.arange(0,10,dt)

fig, ax = plt.subplots()
courbe, = ax.plot([],[])

ax.set_xlabel("x (en m)")
ax.set_ylabel("y (en m)")
ax.set_xlim(0, 5*periode_spatiale)
ax.set_ylim(-1.5*A, 1.5*A)
ax.grid(True)

time_text = ax.text(0.3, 0.95, '', transform=ax.transAxes) # Affichage d'un "timer"

def update(t):
    y =  A *np.cos(2*np.pi*t/T - 2*np.pi*x/(c*T))
    courbe.set_data(x, y)
    time_text.set_text('Temps écoulé = {:.2f} s'.format(t))   
    return courbe,time_text

animation = ani.FuncAnimation(fig, update, frames=temps, interval=20, repeat=False, blit=True)

plt.show()

    Le programme précédent trace une onde sinusoidale progressive de fréquence f qui se propage dans la direction de l'axe (Ox) dans le sens des x positifs à la célérité c.
    La classe FuncAnimation appelle la fonction update qui met à jour le graphique tous les 20 ms en traçant l'onde dans l'espace sur l'intervalle \([0;5\lambda]\), à un temps t variant de 0 à 10s avec un pas dt.
    Un timer est aussi affiché donnant le temps écoulé depuis l'instant t = 0.
