    6. Boucles bornées et non bornées

    Une boucle est une structure permettant de répéter un bloc d'instructions plusieurs fois. Il existe deux façons de répéter le bloc d'instruction :

    • soit tant qu'une condition est vraie : il s'agit de la boucle non bornée while
    • soit en un nombre de fois fixé : il s'agit de la boucle bornée for

    6.1 Comment créer une boucle non bornée ?

    Pour créer une boucle non bornée, il faut utiliser la syntaxe suivante : 

    1
2
3
4
    while condition : 
    instruction1
    instruction2
    ....
    Remarques :

    • le mot clé while peut se traduire par : "Tant que".
    • Attention à l'indentation des instructions à l'intérieur de la boucle !
    Test 6.1.1 : Boucle While
    1. Ecrire un programme permettant d'afficher les 30 premières positions d'une trajectoire soit M1, M2, ..., M30

    i=1 #initialisation

while i<=30 :  # Tant que i<=30
    print("M{}".format(i)) #afficher Mi
    i = i + 1 #incremente i de 1

    6.2 Coment créer une boucle bornée ?

    Pour créer une boucle bornée, il faut utiliser la syntaxe suivante : 

    1
2
3
4
    for element in iterable : 
    instruction1
    instruction2
    ....
    Remarques :

    • for element in iterable peut se traduire par : "Pour chaque élément dans l'itérable"
    • Un itérable est un objet dont on peut parcourir ses valeurs une à une. Par exemple : une liste, un texte, ...

    print(lettre)        #afficher lettre

for n in range(3) : # la fonction range() génère une suite de nombres de 0 à 2 avec un pas de 1 
    print(n)        #La boucle s'éxécute 3 fois de suite

    liste = [("Cyclohexane",6.5), ("Eau",0) , ("Ethanol",114) , ("Methane",-182.5), ("Acetone",-94.6), ("Sel",801)]

temperature = 20 #en °C

for data in liste:
    espece = data[0]
    t_fus = data[1]
    if temperature <= t_fus:
        etat = "solide"
    else :
        etat = "pas solide"
    print("{} : {}".format(espece,etat))
