    2. Variables

    Une variable est un emplacement de la mémoire où l'on va stocker une donnée.

    2.1 Comment créer une variable ?

    Pour créer une variable, il suffit de définir un nom pour la variable suivie de l'opérateur affectation de symbole = et de la donnée à stocker. Voici un exemple : 

    1
    concentrationmolaire = 1.5 #en mol/L
    Dans cet exemple, on a créé une variable nommée concentrationmolaire à laquelle on a affecté la donnée 1.5 par le symbole =.
    #en mol/L est un commentaire.

    2.2 Peut-on donner n'importe quel nom à une variable ?

    Non, il y a des règles de syntaxe à respecter.

    Le nom est sensible à la casse et ne doit pas :

    • commencer par des chiffres
    • avoir des espaces ou d’accents
    • être un mot « réservé à Python» tel que from, if, for, else, …

    Mais il peut contenir :

    • des lettres minuscules (a à z) Ex : concentrationmolaire = 2
    • des lettres majuscules (A à Z) Ex : ConcentrationMOLAIRE = 0.0010
    • des nombres (0 à 9) Ex : concentrationMolaire458 = 5e-2
    • le caractère (_) Ex : _Concentration1_Molaire_1a = 13.5

    Pour avoir un code compréhensible, il est recommandé d'utiliser des noms de variables significatifs.

    Une canette de soda de 33 cL est remplie de mercure liquide de masse volumique de 13,5 kg/L.
    1. Créer des variables correspondantes aux grandeurs physiques de l'énoncé.
    2. Executer le script et explorer les variables dans l'explorateur. 

    1
2
    volume = 33 #en cL
masse_volumique = 13.5 # en kg/L

    2.3 Comment afficher simplement le contenu d'une variable ?

    Pour afficher le contenu d'une variable, il suffit d'utiliser la fonction print() en passant en argument la variable. La fonction renvoie alors le contenu dans la console python sous la forme d'une chaîne de caractère. On peut aussi utiliser l'explorateur de variable pour voir directement le contenu.

    Test 2.4 : fonction print()

    La densité du cyclohexane vaut 0.779
    1. Créer une variable correspondante à la grandeur physique de l'énoncé.
    2. Afficher la valeur de la variable. 

    1
2
    densite_cyclohexane = 0.779
print(densite_cyclohexane)
