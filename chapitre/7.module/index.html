    7. Modules

    Avant de définir un module et afin de mieux appréhender ce chapitre, on va introduire quelques notions sur la programmation orientée objet et les classes.

    7.1 Programmation orienté objet et notion de classe

    Une classe est une structure qui contient des variables et des fonctions. En programmation orienté objet, on utilise ces structures pour créer des objets (une personne, un bien matériel, une entité physique, ...). C'est en quelque sorte le plan de fabrication de l'objet. Dans cette structure, les fonctions représenteront ce que l'objet sait faire : ce sont les méthodes et les variables représenteront les propriétés de l'objet : ce sont les attributs.

    • Par exemple, on peut créer un personnage avec une classe Personnage. Ce personnage peut se déplacer, parler avec un autre personnage, manger, ... Ces actions seront définies par des méthodes (fonctions). De plus, ce personnage possède des cheveux, des yeux, une taille, un âge, ... Ces propriétes seront définies par des attributs (variables).

    • De même, en physique-chimie, on pourrait créer une classe SolutionAqueuse. Cette solution possède une masse, un volume, une concentration, ... . Ces propriétes seront définies par des attributs (variables). De plus, cette solution peut-être diluée, titrée par une autre solution,... . Ces actions seront définies par des méthodes (fonctions).

    Ainsi avec cette façon de penser, on se retrouve avec du code où de nombreux objets interagissent entre eux et non plus avec du code contenant de simples fonctions et variables isolées. Les fonctions et les variables sont ainsi encapsulées dans l'objet. L'intérêt de ce concept largement utilisé dans le monde de l'informatique est d'avoir un code plus lisible, cohérent, robuste, évolutif et modulaire. Cela évite de réécrire du code identique pour des objets similaires et permet de réduire les erreurs. Chaque objet peut ainsi être développé, testé et utilisé indépendamment.

    Il faut bien comprendre que dans Python, TOUT est objet. L'objectif, ici, n'est pas de construire nos propres classes mais de comprendre comment s'en servir. Par exemple, les données vues dans le chapitre 3 sont toutes des objets construits à partir de classe. Nous avions même utilisé des méthodes sur ces objets.

    7.2 Revenons aux modules

    Un module est un fichier ou plusieurs fichiers contenant un ensemble de variables, de fonctions, d'objets, de classe, de structures prêts à l’emploi, que l’on peut importer dans un programme.
    Ex : racine carrée, sinus, visualisation de courbe, résolution d’équations, modélisation de données, ...

    Cela permet de gagner du temps, de réduire les risques d'erreur, d'avoir un code plus lisible et surtout de réaliser des tâches complexes en quelques lignes de code. En effet, il n'est pas toujours utile de vouloir réinventer la roue surtout que les contenus des modules sont testés, fiables et optimisés.

    Python possède une vaste collection de bibliothèques. Voici quelques modules scientifiques utiles à la programmation en physique-chimie au lycée et bien au delà :

    • math : pour les bases mathématiques de la bibliothèque standard de Python.
    • numpy : pour le calcul scientifique déja installé avec Spyder.
    • scipy : pour la modélisation scientifique déja installé avec Spyder.
    • matplotlib : pour la visualisation graphique déja installé avec Spyder.
    • panda : pour la science des données déja installé avec Spyder.

    Il faut savoir que tous les modules sont programmés en orienté objet. Les modules dans Python sont donc des objets.

    7.4 Comment importer et utiliser les objets contenus dans un module ?

    Une fois que le module que l'on souhaite utilisé est bien installé, il y a deux façons de les importer :

    • avec import nom_du_module
    • avec from nom_du_module import nom_objet

    Test 5.4.1 : Module numpy

    On souhaite utiliser la variable pi et la fonction sin() (voir doc) disponible dans le module Numpynumpy afin de faire un calcul.

    1. Tester le code suivant : 

      1
2
3
4
5
      #1ere façon d'importer
import numpy   
angle = numpy.pi/2 
y = numpy.sin(angle)
print(y)

    2. Tester le code suivant : 

      1
2
3
4
5
      #2eme façon d'importer
from numpy import pi,sin  
angle = pi/2 
y = sin(angle)
print(y)

    Avec la 1ère façon, il faut bien comprendre que :

    • à la ligne 1, on importe le module numpy au début.
    • à la ligne 2, numpy.pi signifie qu'on accède à l'attribut pi contenu dans l'objet numpy. Le . est très important comme nous l'avons vu précedemment.
    • à la ligne 3, numpy.sin(angle) signifie qu'on utilise la méthode sin() contenue dans l'objet numpy avec pour argument angle. Cette fonction renvoie alors la valeur du sinus dans la variable y.
    • Dans l'explorateur de variables, pi et sin() n'apparaissent pas alors que le module numpy oui.

    Avec la 2ème façon, il faut bien comprendre que :

    • à la ligne 1, dans le module numpy, on importe directement la variable pi et la fonction sin() dans le script.
    • à la ligne 2, pi est une variable de notre script et est utilisée directement.
    • à la ligne 3 sin(angle) est une fonction de notre script et est utilisée directement.
    • Dans l'explorateur de variables, pi et sin() apparaissent alors que le module numpy non.

    Cette 2ème façon d'importer n'est pas recommandée car cela peut créer des conflits dans le script si on dispose déja de variables nommées pi ou de fonction nommée sin() qu'on a importé d'un autre module ou qu'on a créé nous mêmes. Il vaut mieux privilégier la programmation orientée objet avec import et l'utilisation du .

    Parfois il s'avère que la méthode que l'on souhaite utiliser se trouve dans un "sous-module" du module.

    7.5 Et si je veux créer mon propre module ?

    Pour créer de manière simple son propre module, il suffit :

    • de créer un fichier appelé par exemple mon_module.py et de le placer dans le même dossier que le fichier du programme principal.
    • dans le fichier mon_module.py, créer des variables et des fonctions.
    • puis dans le fichier principal importer le module mon_module.py avec import mon_module
    • enfin appeler les variables avec mon_module.ma_variable1 et les fonctions mon_module.mafonction1(...)

    Cela va de soit que si vous souhaiter un module robuste et extensible, il faudra se lancer dans la programmation orientée objet
